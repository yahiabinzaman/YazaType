STEP-BY-STEP SETUP

Get Started in 3 Simple Steps

macOS SETUP

macOS (Ventura, Sonoma, Sequoia)

1. Run the 1-line terminal command or download YazaType.dmg.

2. Open System Settings → Keyboard → Input Sources (Edit...). Click +, search for YazaType, and add it.

3. Press Control + Space or tap Globe (🌐) key to switch anytime.

Download YazaType.dmg
WINDOWS SETUP

Windows 10 / 11

1. Run the 1-line PowerShell script or download YazaType.exe.

2. If Windows SmartScreen appears, click "More info" → "Run anyway".

3. Press F12 anytime to toggle between English and Bengali mode.

COMMON QUESTIONS

Frequently Asked Questions

Is YazaType the best Bangla keyboard for Mac and a modern Avro alternative?
Yes! Legacy Avro Keyboard for Mac hasn't been updated for modern macOS (macOS 12 Monterey through macOS 15 Sequoia) and often crashes on Apple Silicon (M1/M2/M3/M4) chips. YazaType is natively written using Apple's InputMethodKit framework, providing zero-lag typing, identical Avro phonetic rules, National & Probhat layouts, and instant Unicode & Bijoy ANSI switching with 100% offline privacy.
Who developed YazaType?
YazaType was engineered and developed by Yahia Bin Zaman (ইয়াহিয়া বিন জামান), a software engineer and creative technologist with 8+ years leading design, prepress manufacturing, and ERP systems at ColorLab.
Why does Windows show "Windows protected your PC" when opening YazaType?
YazaType is 100% open-source, non-profit software without an expensive corporate digital signature certificate. When Windows Defender SmartScreen appears, simply click "More info" and then "Run anyway". It is completely safe, offline, and contains zero tracking code.
How do I type in Adobe Illustrator without broken vowel boxes?
Simply switch YazaType's Output Encoding to ANSI from the macOS Menu Bar or Windows Tray. In Illustrator or Photoshop, select your ANSI font (e.g. SutonnyMJ) and type normally. YazaType automatically reorders all vowels and conjuncts in real-time.
Does YazaType collect any typing data or keystrokes?
No! YazaType is 100% offline, open-source, and has zero network permissions. None of your keystrokes or data ever leave your computer.
How do I toggle between English and Bengali?
On macOS, use Control + Space or the Globe key. On Windows, press F12 anytime to toggle between English and Bengali mode.
